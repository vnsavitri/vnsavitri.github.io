# vnsavitri.github.io

Personal site at [vnsavitri.github.io](https://vnsavitri.github.io). Built with [Astro](https://astro.build) and [Tailwind](https://tailwindcss.com). Deployed to GitHub Pages via Actions.

## Local development

```bash
npm install
npm run dev      # http://localhost:4321
npm run build
npm run preview
```

## Adding a project

Drop a new markdown file in `src/content/projects/`. Frontmatter schema is in `src/content.config.ts`.
