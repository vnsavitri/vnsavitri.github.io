What's new in Claude Code

Five things that actually shipped between May and July 2026, each one checked against Anthropic's documentation before it made the page.

Artifacts

A working session can now be published as a live web page at a private link: PR walkthroughs, incident timelines, and dashboards that keep refreshing as the session runs.

In-app browser

A sandboxed browser pane sits next to chat, diff, and terminal, so Claude can open docs, designs, or a local dev server and look at what it built without leaving the app.

Source: code.claude.com/docs/en/desktop-quickstart
Available now Desktop app · 10 Jul 2026
$ /doctor

/doctor

Runs a full setup checkup on installation, configuration, and MCP connections, then offers to fix what it finds. A July update folded in cleanup suggestions for stale skills and unreachable permission rules.

Source: code.claude.com/docs/en/commands
Available now Built-in command

Agent view

One screen to dispatch, watch, and step back into background sessions, so a bug fix or a flaky-test hunt doesn't get lost in a wall of terminal scrollback.

Source: code.claude.com/docs/en/agent-view
Research preview Interface may still change
$ /bg

Background agents

Send a session to the background from agent view and keep working in the foreground. Each one keeps running without a terminal attached, ready to reattach to whenever it needs you.

Source: code.claude.com/docs/en/agent-view
Research preview Same feature family as agent view

Why it's worth five minutes

Ship faster

Agent view and background sessions mean you're not stuck waiting on one task before starting the next.

Private by default

Artifacts stay inside your organisation until someone with access chooses to share them further.

Fewer surprises

/doctor catches install, config, and MCP issues before they cost you an afternoon of guessing.

Full visibility

The in-app browser lets Claude check its own work in a real page instead of asking you to look.

Still evolving

Agent view and background agents are both research previews, so expect the interface to keep moving.
