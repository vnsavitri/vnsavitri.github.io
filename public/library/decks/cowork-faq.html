Claude CoWork — Frequently Asked Questions

For BRG staff and Workstream Leads · Covers setup, connectors, data, and support
Start here if you're new. Claude CoWork is the desktop app version of Claude — it runs locally on your machine, reads and writes your local files, and keeps memory between sessions. It's different from claude.ai (the browser). If you're unsure whether to use Claude Chat, CoWork, or Claude Code, check the Chat vs CoWork vs Code 1-pager first.

Getting Started
What exactly is Claude CoWork?

Claude CoWork is a desktop app that runs Claude AI locally on your Mac or Windows machine. Unlike Claude Chat (which runs in a browser and has no persistent memory), CoWork:

  • Reads and writes files directly on your computer — no cloud upload limits
  • Remembers your preferences and context across sessions via a memory.md file
  • Returns ready-to-use files in your local folders, not just text in a chat window
  • Connects to Outlook, Confluence, and Slack via approved connectors

Think of it as Claude that lives on your machine, knows your context, and works in your files.

What's the difference between Claude Chat, Claude CoWork, and Claude Code?
ToolWhere it runsBest forNot ideal for
Claude Chat Browser / mobile / desktop app (claude.ai) Quick questions, drafts, summaries, exploration. No setup needed. Working with large local files; tasks needing memory across sessions
Claude CoWork Desktop app — installed locally, connects your tools Working with local files, automating recurring tasks, persistent memory, outcome-first prompting (get a finished file, not a chat reply) Real-time sharing or collaboration — each machine is sandboxed
Claude Code Terminal / CLI — requires technical setup Agentic coding, multi-step technical tasks, developer workflows Non-technical users; everyday work tasks
Not sure? Start with Claude Chat. It's the easiest on-ramp and runs in your browser with no setup.
How do I install CoWork and set it up for the first time?

Step 1: Download and install the Claude desktop app from BRG Company Portal (Mac and Windows supported).

Step 2: Open the app and sign in with your BRG login crediential.

Step 3: Create a local folder in your Documents — name it something like CoWork or AI Workspace.

Step 4: In CoWork, click "Choose a folder" and select the folder you created. This is your workspace.

Step 5: Add a claude.md file to that folder (your personal instructions to Claude) and a memory.md file (where Claude stores notes about your preferences).

Vivid has built a pre-made HTML template (CoworkOS setup guide) to shortcut steps 3–5.
What is a "Project" in CoWork? Why can't I see my colleague's files?

In CoWork, a "Project" is a local folder on your machine. CoWork is sandboxed — it can only see files inside the folder you've pointed it to. Each user's workspace is separate.

This means:

  • Your CoWork setup doesn't automatically share with anyone else
  • There's no live collaboration or co-editing across machines in CoWork
  • If you want to share output, export the file manually (or put it on OneDrive/SharePoint)
⚠️ Note: "Projects" in CoWork is not the same as "Projects" on claude.ai. They share a name but work differently. CoWork projects are local folders; claude.ai projects are cloud-based conversation buckets.

If real-time sharing is your primary need, CoWork may not be the right tool — raise this with your Workstream Lead and check if ChatGPT Workspace Agents (cloud-native, currently under security review) might be a better fit.

What is CoworkOS? Do I need it?

CoworkOS is a setup pattern developed by Vivid Savitri that turns CoWork into a personalised AI operating system with persistent memory and structured workstations. It's built on top of standard CoWork using markdown files.

The pattern uses a single HTML template you copy and customise. Each "workstation" (e.g., Email HQ, Project Hub) has four parts: identity, resources, workflow, editorial role.

Do you need it? Not immediately. Start with basic CoWork first. Once you find yourself repeating the same prompts 2–3 times a week, that's the signal to set up a workstation or skill.

CoworkOS can be mastered in about 20 minutes.

Why does CoWork say my connector is "blocked"?

This might happen due to BRG browser/network policy setting, not necessarily CoWork bug.

What to do:

  • Check the "What's Allowed at BRG" page — it lists which connectors are approved and any steps needed to enable them
  • If a connector you need isn't on the approved list, raise it via the AI tool evaluation form or the AI Slack channel
  • Contact your Workstream Lead if you're unsure — they're the first port of call for function-specific connector questions
CoWork can't read my Outlook drafts or send emails — is that a bug?

No, this is by design. The Outlook connector in CoWork is currently read-only. CoWork can read your inbox and calendar but cannot compose or send emails on your behalf.

The workaround most users adopt:

  • Ask CoWork to draft the email as a text file or copy it to your clipboard
  • Paste manually into Outlook and send from there
How do I access files in SharePoint from CoWork?

CoWork cannot connect to SharePoint directly. The supported workaround is to use OneDrive sync:

  • Sync your SharePoint library to your local machine via OneDrive (right-click the SharePoint library in your browser → "Sync")
  • The synced folder appears in your Windows Explorer / Finder as a local folder
  • Add that folder to your CoWork workspace, or copy files from it into your CoWork folder
  • Changes you save back to the OneDrive-synced folder will sync to SharePoint automatically

Data, Privacy & Security
Is it safe to put BRG data into CoWork?

Claude CoWork is on BRG's approved tool list. Anthropic's enterprise data commitments include:

  • Conversations and files are not used to train Anthropic's models
  • Data is encrypted in transit and at rest
  • Enterprise accounts are isolated from consumer accounts

General guidelines for what's appropriate:

  • ✓ Internal documents, drafts, reports, analysis — fine
  • ✓ Meeting notes, presentation prep, email drafting — fine
  • ~ Commercially sensitive strategy documents — use judgement; check with your manager if unsure
  • ✗ Customer personal data (PII) — do not paste raw PII into any AI tool without explicit guidance from Privacy team
If in doubt about a specific data type, ask your Workstream Lead or contact Madison Sertic (Privacy).
What about AI-generated images or likenesses?

AI-generated images that depict real people require release forms from those individuals. This applies to any AI image generation tool, not just CoWork.

Before using AI-generated images of real people in any production content:

  • Consult Annabela Lima (Privacy/Security) and Madison Sertic (Privacy)
  • Confirm: Is the depicted person real or synthetic? Were they consented? Where was the source image from?

This applies to content generation tools broadly (Nano Banana 2, GPT Image 2, etc.).

Does CoWork use my data to train Claude?

No. BRG operates under an enterprise Anthropic agreement. The agreement explicitly covers:

  • BRG will not use customer personal data to train external AI models without explicit consent
  • Data you share in CoWork is not used to train Anthropic's models

This is consistent with BRG's AI Governance Statement (under Board review since Oct 2025).

Using CoWork Day-to-Day
What is "outcome-first prompting" and why does it matter?

Outcome-first prompting means starting with the finished result you want, not a step-by-step instruction set. Instead of "write me a brief about X, then format it, then add a summary," you say: "I need a two-page brief on X saved as brief-X.docx in my Documents folder."

CoWork is designed for this. Because it has access to your local files and persistent memory, it can carry out multi-step tasks and produce files directly — not just give you text to copy out of a chat window.

The "walk away" pattern: give CoWork the outcome you need, let it run, come back to a finished file. This is the primary value shift from using Claude Chat.
What's the best way to handle large files or multiple documents?

This is one of CoWork's strongest differentiators. Because it accesses local files directly (no browser upload limit), you can:

  • Point CoWork at a folder of PDFs and ask it to synthesise across all of them
  • Work with large Excel files without hitting browser upload caps
  • Process multiple documents in a single session
Can I share my CoWork setup or templates with my team?

Not automatically — CoWork is sandboxed per machine. But you can share the setup files manually:

  • Share your claude.md and memory.md templates via Teams/SharePoint
Real-time collaboration (co-editing a live document together) is not supported in CoWork. If that's your primary need, ChatGPT Workspace Agents (currently under BRG security review) may be worth watching — it connects directly to SharePoint and Jira.
Which Claude model should I use in CoWork?

CoWork gives you model options within the app. Vivid's guidance (May 2026):

  • Claude Opus — Use for planning and complex reasoning only (it's expensive; ~5× the cost of standard)
  • Claude Sonnet — Use for execution, drafting, and day-to-day tasks. Best balance of quality and cost.
  • Claude Haiku — Use for fast, repetitive tasks (e.g., daily briefings, formatting) where speed matters more than depth
Many users default to Opus without realising the cost difference. If you're not doing complex reasoning, switch to Sonnet — same quality for most tasks, significantly cheaper on BRG's usage-based licence.
What are "Skills" and how do I use them?

A Skill is a reusable, multi-step workflow you can trigger with a single click or phrase — essentially a saved prompt sequence. Example skills from the pilot:

  • Daily briefing: summarise my Outlook inbox and calendar, prioritise by current week's focus
  • Meeting prep: pull the agenda, read relevant Confluence pages, draft talking points
  • Weekly report: pull data from a folder, synthesise into a formatted report

When to build a Skill: When you find yourself doing the same task 2–3+ times per week. Don't build Skills prematurely — understand the workflow through iteration first.

Vivid's CoworkOS setup guide walks through how to create your first Skill from a recurring task.
