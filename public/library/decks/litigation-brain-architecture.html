01 The Concept

What you described is feasible.
The architecture just works differently.

Your instinct is exactly right: Claude can synthesise knowledge across all past matters to reduce costs on future litigation. The setup is simpler than you might expect.

✕ Common assumption

Separate "Projects" that a Brain bridges

Each lawsuit lives in its own CoWork Project — and a central Brain has special access across all of them, like a hub that connects separate silos.

CoWork Projects are sandboxed local folders. There's no native cross-project bridge. This architecture won't work.
✓ How it actually works

One shared folder — every matter inside it

All lawsuit materials live in a single shared workspace on OneDrive. Each matter is a subfolder. Because Claude sees everything inside one workspace, it already synthesises across all of them — automatically.

Same outcome you described. Simpler architecture. Achievable this month.
The key insight: Claude doesn't need a special feature. Because every matter lives inside the same workspace folder, Claude can read and connect them all in a single session. The Brain is the folder.

📍 Sandboxed by design

Claude only sees files inside the folder you've pointed it to. This is a security feature — your data stays local, and Claude cannot reach outside the workspace.

07 Governance & Access Control

Not everyone needs edit rights.
Most people shouldn't have them.

Ten people with full edit access to a folder of sensitive litigation documents is a data integrity risk. The right model uses tiered permissions — and OneDrive's built-in version control as the safety net.

🔁

Automatic version history

OneDrive (SharePoint) keeps up to 500 versions of every file automatically. Any document — including CLAUDE.md — can be restored in one click. Nothing is permanently deletable without deliberate action by an Owner.

👥

Azure AD group management

Access is managed via Azure AD groups — not individual invitations. When someone leaves Legal, IT removes them from the group and access is revoked across the entire folder structure simultaneously.

Version control & safety net

🕐

500-version file history

SharePoint keeps every saved version automatically. Right-click any file → Version history → restore in one click. Works on CLAUDE.md, matter documents, everything.

🗑️

Recycle bin protection

Deleted files go to the OneDrive recycle bin for 93 days before permanent removal. Only an Owner can purge. Accidental deletion is fully recoverable.

📋

Audit log

SharePoint logs every file access, edit, download, and deletion with timestamp and user. Exportable by IT or Legal admin. Supports any compliance or LPP audit trail requirement.

Setup note: Savannah (as Brain Admin) or IT can configure these permission tiers in SharePoint admin in under 30 minutes. The AI CoE will provide a permissions checklist as part of the 90-min setup session.
