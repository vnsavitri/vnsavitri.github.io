Open Multi-Agent Interactive Classroom

Teach with a room full of agents.

OpenMAIC turns a topic or source material into an interactive classroom: lessons, quizzes, simulations, project work, voices, whiteboards and AI classmates — with a path from one-click generation to a steerable course-building workbench.

Deep dive • evidence • architecture • implementation guide
Prepared 19 September 2026

01 / Plain EnglishTL;DR beginner first

It is a classroom generator that can keep teaching after the first draft.

Give OpenMAIC a topic, slides or other materials. It can build a structured course, populate it with different AI roles, and let a learner interrupt, ask, explore, practise and export the result.

Build faster

Move from a prompt or source pack to a usable lesson rather than starting with a blank page.

Make learning social

Use teacher, assistant, manager and classmate roles to create a more alive learning loop.

Keep steering

In Pro mode, sessions can be resumed, redirected and revised instead of regenerated from scratch.

The core idea: MOOCs optimise distribution. MAIC adds an adaptive, multi-agent layer around the course so the learner can shape the session as it unfolds.
Source: OpenMAIC repository · MAIC paper
02 / The opportunityscalability × adaptivity

The tension is simple: reach many people without teaching everyone the same way.

MOOC pattern

One course, many learners

  • Pre-recorded content is efficient to distribute.
  • Everyone gets roughly the same pace and explanation.
  • Personal support is expensive and often missing.
→
MAIC pattern

One learner, many agents

  • Course material becomes structured, searchable and actionable.
  • Agents can explain, question, manage, encourage and analyse.
  • The learner can interrupt and steer the classroom.

The paper frames this as a design goal, not a solved problem: balancing scalability with adaptivity through LLM-driven multi-agent systems.

Source: From MOOC to MAIC, pp. 1–3

The interesting part is not “many agents” by itself. It is the combination of structured course material, explicit actions, role design and a controller that keeps the room moving.

04 / Deep divepaper architecture

The preparation workflow has two passes: understand the material, then make it teachable.

01 READExtract

Capture textual and visual content from each page.

02 READDescribe

Generate a usable description for the slide or source unit.

03 READStructure

Build a knowledge-aware tree across the material.

04 PLANReview

Let educators proofread and refine the machine output.

05 PLANCompose

Attach actions, scripts and agent roles to the course.

Why structure matters

A slide deck is not yet a learning system. OpenMAIC converts pages into descriptions, knowledge units and action-ready material that agents can retrieve and use.

Human checkpoint

The paper keeps educators in the loop for proofreading and refinement. That is a crucial product choice: generation is accelerated, not made unquestionable.

Source: MAIC paper, §3.1 and Figure 2
05 / Deep dive1 learner + N agents

Roles give the room a division of labour.

Teacher

Explains, asks, advances the lesson.

Assistant

Supports, clarifies and helps manage.

Classmates

Challenge, react, summarise or energise.

session controller
Who
speaks next?

Reads the current state, available actions, class roles and learner input, then advances the classroom.

Manager

Maintains flow, timing and classroom order.

Analyzer

Reads signals from behaviour and outcomes.

Learner

Interrupts, asks, steers and chooses depth.

Product insight: role design is a UX primitive. It makes behaviour legible, lets users choose the social texture of a class, and gives routing decisions something concrete to optimise.
Source: MAIC paper, §3.2 · OpenMAIC features

07 / Deep diverepository map

OpenMAIC has evolved from a concept into a fairly complete product surface.

Generation

Two-stage outline → scene generation, with multimodal materials, scripts, media and classroom scenes.

Orchestration

LangGraph-based multi-agent discussions, playback state, action execution and interactive classroom control.

Persistence

Browser-first by default, with optional PostgreSQL-backed documents, assets, materials, sessions and skills.

Editor + renderer

Versioned DSL, slide editor, scene renderers, PPTX importer and HTML/PPTX export packages.

Media surface

Pluggable providers for LLMs, search, images, video, TTS and ASR, including local options.

Agent workbench

Chat-first Pro mode with durable sessions, follow-up steering, materials and reusable course skills.

Read this as a system boundary: OpenMAIC is not one prompt wrapper. It is an authoring, runtime, playback, storage and export stack.

Source: OpenMAIC project structure and key architecture

09 / Deep diveevidence, not hype

The evidence is encouraging, but the paper itself calls it preliminary.

Teaching-side evaluation · 5-point scale
MAIC-FuncGen4.00
SCP baseline3.90
Human baseline3.86
w/o visual3.61

MAIC-FuncGen scored highest overall in the paper’s script-generation comparison. Visual input and prior context mattered.

Behavioural study
61%

of observed student activity involved asking questions or seeking knowledge.

11%

involved managing progress or agent roles.

The study covered more than 500 students and 100,000 learning records across two courses. These are observations and associations, not a randomised proof of causation.

What seems to work

Structured visual context, role descriptions, immediate Q&A and explicit classroom actions.

What remains weak

Controller accuracy, deep discussion, personal adaptation and the risk of mechanical teaching.

What to measure next

Direct assessments of critical thinking, problem solving, retention and transfer, not only perceptions.

Source: MAIC paper, §§4–5
10 / Deep divewhat to borrow

The strongest idea is not “replace teachers”. It is “make learning stateful, inspectable and steerable”.

A

Make the state explicit

Track current scene, learner signals, role availability, pending actions and course context.

B

Give agents boundaries

Use role descriptions, tools and routing rules so each agent has a job it can perform well.

C

Design for interruption

Let people pause, ask for a simpler explanation, change pace or revisit a previous step.

For an AI product team: the opportunity is an orchestration layer around content, not just a better prompt. The evaluation target becomes the quality of the learning loop.
Interpretation based on the paper and repository architecture. See agent workbench and MAIC paper.

without overbuilding

Start with one classroom, one provider and one measurable learning outcome. Add the multi-agent and persistence layers only when they solve a real bottleneck.

11 / Implementationthree sensible paths

Choose the smallest setup that matches your goal.

PathUse it whenWhat you doTrade-off
Hosted demoExplore the experience quickly.Get an access code and use the live deployment.Fastest start; less control.
Local devBuild a course or prototype locally.Clone, install, configure one LLM provider, run pnpm dev.More setup; easiest to debug.
Extend / deployOwn the product surface or run shared sessions.Use the SDK/packages, agent runtime, PostgreSQL and a production deployment.More control; security and operations become your job.

My recommendation

Use local dev for a first serious prototype. Keep the hosted demo for experience testing. Add server-backed persistence only once sessions or assets need to survive devices and restarts.

Do not skip

Decide who owns learner data, which providers receive source materials, and whether generated classrooms are public, private or access-code protected.

Source: OpenMAIC Quick Start · startup modes
12 / Implementationlocal dev path

Get a first classroom running in four moves.

Clone and install

Use Node.js ≥ 22.19 and pnpm ≥ 10, then install the workspace dependencies.

Configure one provider

Copy .env.example to .env.local and set a provider key plus an explicit DEFAULT_MODEL.

Start locally

Run pnpm dev, then open the local app and create a small test course.

Verify the loop

Check outline quality, scene transitions, questions, exports and what source data is retained.

# prerequisites: Node.js >= 22.19, pnpm >= 10 git clone https://github.com/THU-MAIC/OpenMAIC.git cd OpenMAIC pnpm install cp .env.example .env.local # edit .env.local yourself OPENAI_API_KEY=sk-... DEFAULT_MODEL=openai:gpt-... pnpm dev # health check curl -fsS http://localhost:3000/api/health
Important: OpenMAIC’s own setup guidance says it does not automatically reuse another agent’s key or model. Configure the server-side provider explicitly.

14 / Implementationwhen it becomes a system

For shared or long-running classrooms, persistence and security change the design.

Optional production layers
  • PostgreSQL-backed course documents and runtime state.
  • Durable agent sessions with leases, heartbeats, resume and cancellation.
  • Asset registry and storage, with retention and quota decisions.
  • Access code or real user authentication for shared deployments.
  • Render service for MP4 export when required.
Guardrail checklist
Data boundaries

Do not send private course or learner material to an unapproved provider.

Action boundaries

Keep consequential operations explicit, logged and reversible where possible.

Learning boundaries

Measure actual skill transfer, not only pleasant interaction or message volume.

Read the repo’s warning carefully: the development persistence token is not meaningful confidentiality or user isolation. Treat the reference server as a local/trusted-network setup until you add real identity and authorisation.

16 / Closethe short version
One sentence
OpenMAIC is a course runtime where content, agents and learner intent can move together.

The next product frontier is not just generating more lessons. It is making the learning loop observable, steerable and genuinely useful.

01Can the system sustain deep thinking, not just fluent explanation?
02How should human educators inspect and override agent decisions?
03What evidence proves transfer beyond self-report and chat activity?
04Which modalities improve learning, and which are only decoration?
