Sesame Street Emergency Preparedness App

23 April 2014

visit mobile site best viewed on android

overview

in collaboration with Sesame Street Workshop, we created an interactive web app that helps children in rural China prepare for an emergency situation.

designed specifically as a mobile HTML site for Android users, the mobile site features Sesame Street's Grover to guide children through a series of mini-games and activities while teaching crucial life-skills and lessons.

role + responsibilities

creative director

  • responsible for the overal UX design and usability of the mobile site
  • led team of designers and developers to deliver scalable mobile site that runs on Android devices

**client**
sesame street workshop | **china**

deliverables
the mobile site is localised in Mandarin, in which kids can practice writing/memorizing their name, address and emergency contacts.

a mini game like interactive scavenger hunt lets them know exactly what items are important in the face of crisis. Additionally, they will also learn where to go and who to ask for help.

the app was developed for iOS (iPhone/iPad) & Android (smartphone/tablet)

process

agile-led project management with daily stand-up, backlog and unified communication tool using Pivotal Tracker project management tool

tools

HTML 5, Adobe creative suites, test flight and GitHub repository for ongoing prototype and development progress
